The thinking behind StoryCast

Stories should be for everyone.

StoryCast is a learning project exploring how clear design and accessible media can make digital storytelling easier to experience.

Human first

Content is organised around clear stories, straightforward navigation, and plain language.

Access built in

Captions, a transcript, keyboard access, visible focus, and responsive layouts are part of the design.

Honest storytelling

Fictional examples are labelled clearly. Published stories should distinguish verified facts from creative interpretation.

Accessibility checklist

  • Semantic landmarks and logical heading structure
  • Skip link and keyboard-operable navigation
  • Visible keyboard focus indicators
  • Captions and transcript for the featured story
  • Responsive Grid and Flexbox layouts
  • Colour contrast designed toward WCAG AA targets
  • ARIA only where native HTML needs support

These are implementation goals, not formal WCAG certification. Test the final site with keyboard navigation, browser zoom, automated tools, and assistive technology.
